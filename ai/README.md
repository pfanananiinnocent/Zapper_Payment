
# AI-Assisted Development Artifacts

## Purpose

This directory contains supporting artifacts from the
AI-assisted development workflow used to complete the
Zapper Team Lead Software Engineer Technical Vetting Assignment.

The purpose is to demonstrate how AI was used throughout the
software engineering lifecycle, including requirements analysis,
architecture, implementation, troubleshooting, testing,
technical decision-making and documentation.

## AI Tool

ChatGPT was used as the primary AI-assisted engineering tool.

It was used as a collaborative engineering assistant rather
than an autonomous software delivery system.

The developer retained responsibility for reviewing proposed
implementations, making technical decisions, applying changes,
executing the application, investigating failures and validating
the final behaviour.

## Development Approach

The assignment was completed incrementally.

Each major implementation stage followed a feedback loop:

1. Analyse the relevant assignment requirements.
2. Provide AI with the necessary technical context.
3. Discuss implementation options and trade-offs.
4. Generate or refine the implementation.
5. Apply the changes to the local solution.
6. Build and execute the implementation.
7. Validate API responses and database records.
8. Investigate and correct identified issues.
9. Document the results.
10. Commit the validated changes to Git.

## Artifact Authenticity

These documents consolidate the actual AI-assisted development
activities performed during the assignment.

Where original prompts are reproduced, they are identified as
original prompts.

Where discussions are summarised or prompts are reconstructed
for readability, they are identified as retrospective summaries.

The artifacts are not presented as unmodified conversation
transcripts.

## Security and Privacy

Personal information, sensitive credentials and unrelated
conversation content are excluded from the artifacts.

All payment information used during implementation and testing
is synthetic.
